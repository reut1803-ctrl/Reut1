# קליפורניה שלנו ✈️

אפליקציית הטיול של רעות וזכריה. Next.js + Firebase, מתארחת ב-Vercel.
זו אפליקציה **נפרדת** ממערכת השידוכים שבתיקייה הראשית. היא לא נוגעת בה.

## מה כבר בנוי
- שער כניסה עם Google, אנימציית נחיתה, ודמויות שיורדות מהמטוס (אפשר להעלות תמונת פנים).
- שעון חי של קליפורניה ושל ישראל.
- הזמנת בן/בת הזוג לטיול לפי מייל.
- כשההגדרות ב-`src/lib/firebase-config.ts` ריקות, האפליקציה רצה ב"מצב תצוגה" עם התחברות מדומה.

## מבנה הנתונים (Firestore)
```
trips/california                 הטיול: שם, תאריכים, אזור זמן, רשימת מיילים מורשים, תקציב יומי
  members/{uid}                  כל אחד מאיתנו: שם, מייל, תמונת פנים, סגנון דמות
  days/{YYYY-MM-DD}              כל יום: אזור, איפה ישנים, תקציב
  activities/{id}                פעילויות: שעה, מקום, סטטוס (מתוכנן/מושהה/הוזז/בוצע), תזכורת
  places/{id}                    נקודות במפה: אטרקציה, חב"ד, כשר, הדלקת נרות, שיעור תורה, לינה
  packing/{id}                   ציוד לאריזה: פריט, קטגוריה, סומן/לא, מי סימן
  journal/{id}                   יומן הודיה: מי כתב, טקסט, הקלטה קולית, היום
  photos/{id}                    תמונות: קובץ, מיקום, תאריך, מי העלה
  expenses/{id}                  הוצאות: סכום, קטגוריה, יום
```
תמונות הפנים נשמרות כתמונה קטנה ודחוסה בתוך `members/{uid}` (בלי Firebase Storage, שדורש כרטיס אשראי).
`firebase/storage.rules` מוכן לשימוש עתידי, אם נחליט להפעיל Storage לתמונות הטיול.

כללי האבטחה של מסד הנתונים: `firebase/firestore.rules`.
