# "יש לך בית" — עמוד קומיקס (A4)

עמוד רומן גרפי יחיד המספר את סיפור הקמת מיזם השידוכים "יש לך בית".

## תוצרים
- `yesh-lecha-bayit.png` — העמוד המוגמר, A4 ב-300dpi (2485×3515)
- `yesh-lecha-bayit.pdf` — אותו עמוד כ-PDF וקטורי להדפסה
- `page.html` — מקור העמוד (SVG מוטמע, גופנים מוטמעים)

## מבנה
12 פאנלים ב-4 שורות, זרימת קריאה מימין לשמאל.

| שורה | פאנלים (ימין→שמאל) |
|---|---|
| 1 | התסכול · הבדידות · השנה המורכבת (מפוצל לארבע) |
| 2 | הרעיון · המודל הקהילתי · מאמנת החתונה |
| 3 | מסע ההקמה · המיזם נולד · הקריאה לשותפות |
| 4 | חופה · הקהילה · לוגו, קישור ו-QR |

## כללים שנשמרו באיור
- כל הדמויות מאוירות; פנים מסוגננות ולא ריאליסטיות (אנונימיות).
- לבוש צנוע לכל הדמויות הנשיות; אין כיפה על ראשי בחורות.
- אין מגע פיזי בין מאמנת למודרכת ובין בנים לבנות.
- אין סמלים נוצריים; פאנל הזיכרון מרומז — כיסא, טלית, סידור ונר.
- כל הטקסט בעברית, זרימת RTL מלאה.

## בנייה מחדש
```bash
pip install qrcode pillow playwright
cd src && python3 build.py && python3 render.py
```
הגופנים (Frank Ruhl Libre, Heebo, Suez One) נטענים מ-`../fonts` ומוטמעים בקובץ.
המקור הקומפוזיציוני: `lib.py` (פרימיטיבים לאיור), `panels_a.py` (פאנלים 1–6),
`panels_b.py` (7–11), `build.py` (פריסה, טקסטים, פאנל 12).
