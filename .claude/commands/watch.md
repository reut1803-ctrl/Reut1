---

המשתמשת ביקשה לצפות בסרטון: `$ARGUMENTS`

1. הרץ:
   ```bash
   python3 .claude/skills/watch-video/watch.py "$ARGUMENTS" --interval 4
   ```
2. קרא את `watch_output/<שם-הסרטון>/manifest.json`.
3. פתח (Read) כל פריים ב-`frames/` כתמונה — כך אתה "רואה" את הסרטון.
4. הפק **דוח צפייה** בעברית: טבלה (זמן | תיאור חזותי | מה נאמר) + סיכום כללי ורעיונות לכתוביות/עריכה.

אם הסרטון ארוך והתקבלו הרבה פריימים — הרץ שוב עם `--interval 8` או `10`.
